# Windows Computer Running Slowly

> This is a simulated troubleshooting scenario created to demonstrate a structured IT support approach.

## Problem

A Windows computer is experiencing slow performance and takes longer than expected to open applications and complete normal tasks.

## Symptoms

- Applications take a long time to open.
- The computer responds slowly to user commands.
- Startup takes longer than expected.
- Multiple applications may cause noticeable performance degradation.

## Troubleshooting Process

### 1. Gather information

Identify when the performance problem started and whether it affects all applications or only specific programs.

### 2. Check running processes

Use Task Manager to identify applications or processes using unusually high CPU, memory, or disk resources.

### 3. Check available storage

Check the available disk space and determine whether low storage could be contributing to poor performance.

### 4. Review startup applications

Check which applications are configured to start automatically with Windows and identify unnecessary startup programs.

### 5. Check for software issues

Identify recently installed applications or updates that may be contributing to the performance problem.

### 6. Restart the computer

Restart the computer and test whether performance improves.

### 7. Test the result

Open commonly used applications and perform normal tasks to determine whether the system is responding more efficiently.

## Result

The troubleshooting process helps identify whether the performance issue is related to resource usage, storage, startup applications, software, or another system-related cause.
